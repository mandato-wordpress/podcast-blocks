# Project Structure

## Root Files

- `podcast-blocks.php` - Main plugin file (bootstrap, block registration, activation hooks)
- `package.json` - npm scripts for @wordpress/scripts build tooling
- `readme.txt` - WordPress.org plugin repository format
- `CHANGELOG.md` - Version history

## Directory Organization

```
podcast-blocks/
├── admin/                    # Admin-only code (settings page)
│   ├── class-admin.php      # Settings registration, field rendering
│   ├── settings-page.php    # Settings page HTML template
│   └── admin.js             # Media uploader for artwork selection
├── includes/                 # Core functionality (loaded on all requests)
│   ├── class-enclosure.php  # Enclosure meta handler, Apple Podcasts RSS extensions
│   ├── class-podcast-blocks-shared.php  # Shared utilities (Apple Podcasts categories)
│   └── podcast-feed.php     # Custom /feed/podcast template
├── src/                      # Block editor source (ES6+)
│   └── podcast-episode/     # Podcast episode block with player and subscribe modal
├── build/                    # Compiled block assets (generated by npm build)
│   └── podcast-episode/
└── .wordpress-org/           # WordPress.org assets (banners, icons)
```

## Code Organization Patterns

### PHP Classes

- `Podcast_Blocks_Admin` - Admin settings page and field management
- `Podcast_Blocks_Enclosure` - Enclosure meta updates and RSS feed modifications
- `Podcast_Blocks_Shared` - Shared utilities (iTunes categories with translations)

### PHP Functions (Prefixed)

- `podcast_blocks_*` - Global functions (activation, block registration, render callbacks)
- Helper functions in main file: service icons, subscribe services list

### Block Structure

The podcast-episode block directory contains:
- `block.json` - Block metadata (attributes, supports, scripts)
- `index.js` - Block editor registration and edit component
- `style-index.css` - Frontend and editor styles
- `view.js` - Frontend interactivity (subscribe modal)

## Post Meta Fields

All stored with `_podcast_` prefix:
- `_podcast_media_url` - Media file URL
- `_podcast_media_type` - "audio" or "video"
- `_podcast_media_mime` - MIME type (audio/mpeg, video/mp4, etc.)
- `_podcast_media_size` - File size in bytes
- `enclosure` - WordPress standard format: "url\nsize\nmime"

## Plugin Options

Single option array: `podcast_blocks_options`
- Podcast info: title, description, author, email, website, language, explicit
- iTunes: category_primary, category_secondary, artwork_id
- Subscribe links: subscribe_apple, subscribe_spotify, subscribe_audible, subscribe_youtube, subscribe_rss

## WordPress Integration Points

- **Activation**: Schedules rewrite flush for custom feed
- **Admin Menu**: Top-level menu with microphone icon
- **RSS Feed**: Custom `/feed/podcast` endpoint + iTunes extensions on main feed
- **Block Registration**: Dynamic render callbacks for server-side rendering
- **Post Meta**: REST API exposed for block editor access

## Frontend Components

### Subscribe Modal
- Modal overlay with service links (Apple Podcasts, Spotify, Audible, YouTube, RSS)
- JavaScript-powered (view.js) with keyboard navigation and focus management
- CSS classes: `.pb-subscribe-modal`, `.pb-subscribe-modal__box`, `.pb-service`
- Triggered by `.pb-subscribe-btn` link elements

### CSS Class Naming
- Block wrapper: `.wp-block-podcast-blocks-podcast-episode`
- Episode links: `.podcast-episode-links`, `.podcast-episode__link`
- Editor wrapper: `.podcast-episode-editor`
- Player elements: `.podcast-episode__player`
