# Product Overview

**Podcast Blocks** is a WordPress plugin that enables podcast episode management through Gutenberg blocks with Apple Podcasts-compatible RSS feed support.

## Core Features

- **Podcast Episode Block**: Native WordPress media player with Upload/link audio or video files, Download link, and Subscribe modal functionality
- **RSS Feed Integration**: Automatic `<enclosure>` meta generation for WordPress built-in RSS2 feeds
- **Apple Podcasts Compatibility**: Full Apple Podcasts (previously iTunes) RSS extensions (namespace, channel tags, categories, artwork)
- **Subscribe Modal**: Popup with links to Apple Podcasts, Spotify, Audible, YouTube, and RSS feed
- **Admin Settings**: Configure podcast metadata, Apple Podcasts categories, show artwork, and subscribe links

## Target Users

WordPress site owners who want to publish podcasts without third-party hosting platforms.

## Key Workflows

1. Admin configures podcast info and subscribe links in wp-admin
2. Content creators add Podcast Episode block to posts
3. Media URLs are stored in post meta and automatically added to RSS feeds as enclosures
4. Listeners can download episodes or subscribe via the modal popup
5. Podcast directories consume the WordPress RSS2 feed with Apple Podcasts extensions
